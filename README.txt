DARSHAN MATHAPATI PORTFOLIO

FILES
- index.html: main portfolio
- style.css: layout, responsive design, theme
- script.js: hamburger menu, theme toggle, email reveal, GitHub projects
- resume.html: resume page
- resume.pdf: add your current resume PDF here
- photo.jpg: add your portrait image here

HOW TO USE
1. Put all files in the same folder/repository.
2. Add your own photo named photo.jpg.
3. Add your resume PDF named resume.pdf.
4. Open index.html locally, or upload/push all files to your GitHub Pages repository.

AUTOMATIC RESUME UPDATE
Replace resume.pdf in the repository with the newest PDF but keep the exact filename resume.pdf.
After GitHub Pages deploys, resume.html will display the updated PDF. The page adds a cache-busting query to reduce stale browser cache issues. No website code changes are needed for routine resume updates.

GITHUB SETTINGS
script.js uses GitHub username mathapatiappayya88-dm. Change GITHUB_USER if needed.
Update EMAIL_USER and EMAIL_DOMAIN in script.js to your intended public contact email.
The site fetches public GitHub repositories using GitHub's public API. API rate limits or network restrictions may temporarily prevent loading.

NOTE
The resume PDF must be uploaded/replaced by you in the same GitHub repository; the portfolio cannot automatically discover a new file on your computer. Once the PDF is replaced online with the same filename, the resume page updates after deployment/cache refresh.
